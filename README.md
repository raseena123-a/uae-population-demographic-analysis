# UAE Population & Demographic Analysis

## 📌 Project Overview
This project analyzes UAE population growth trends using official World Bank data. 
The objective is to support government-level planning and policy insights.

## 📊 Dataset
Source: World Bank Open Data  
File: API_SP.POP.TOTL_DS2_en_csv_v2.csv

## 🛠 Tools Used
- Python (Pandas, Matplotlib)
- Google Colab
- Excel
- Power BI

## 🔍 Key Analysis
- Population growth trend (1960–2023)
- Year-wise growth rate
- Latest population insights

## 📈 Visualizations
- Line chart showing UAE population growth

## 📁 Files
- `uae_population_clean.csv` – Cleaned dataset
- `.ipynb` – Data cleaning & analysis notebook
